# redesigned-potato

Collection d'outils web HTML autonomes (une page = un logiciel) pour créer des vidéos, des films et des images par IA, principalement via l'API [Agnès AI](https://platform.agnes-ai.com).

Chaque fichier est autonome : ouvrez-le dans un navigateur, collez vos clés API (format `sk-xxxx`, RPM personnalisable) et lancez la génération. Les studios persistants utilisent IndexedDB (sessions, vidéothèque, styles favoris).

## Catégories

- Journaux télévisés / actualité : NewsReel Studio, Cinéma Studio, VISUAL.JOURNAL, Journal Visuel.
- Films et scénarios : Kata Studio, Ciné Studio, Studio d'Auteur, Dessin Animé IA.
- Plans uniques : Plan-Séquence (v15, v23, v26, Studio Plan-Séquence).
- Images et styles : Style Studio, Copy Studio, Studio (variantes blocs / 21 propositions / sessions).
- Divers : APPFORGE (générateur d'applications), MoneyPrinterTurbo · Agnès (vidéos automatiques), ViMax-Agnès Studio, Scene Studio.
